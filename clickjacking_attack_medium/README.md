## Overview
The challenge begins on a main page that has links to three different sites. The player must examine each site and determine which one is vulnerable to clickjacking. After the correct site is marked as vulnerable, a link to the attacker page appears. There, an HTML editor and a preview pane are provided. The objective is to craft an attack that hijacks two sequential clicks (the page will specify the intended action). Once the attack is prepared, it can be delivered to the user. The player then visits the victim page, performs the clicks, and if successful, an alert with the flag will appear.
